# 商品页文案（WorkBuddy / SkillPay）

上传用 `scripts/package_skill.py --for workbuddy` 产出的 `dist/bulk-doc-to-markdown-<版本>-workbuddy.zip`（WorkBuddy）或 `--for skillpay`（支付宝）。两个包内容一样，只有文件名不同。

上传后要在「技能发布管理」里填的介绍与使用说明。平台要求说清四件事：**适合谁、交什么材料、拿到什么结果、有哪些限制**。下面各段可直接复制。

---

## 名称

`bulk-doc-to-markdown`

（技能目录名、`SKILL.md` 的 `name` 都是这个。市场里若有重名，优先报错不要自己改名——目录名和 `name` 必须一致。）

## 一句话介绍

把 PDF、Word、Excel、PPT 和网页转成干净的 Markdown，整个文件夹可以一次转完。

## 适合谁

- 要把一堆资料喂给 AI 的人：论文、合同、财报、课件先转成文本，模型才读得懂
- 做知识库、RAG、笔记归档的人：一个文件夹丢进去，出来一套按原目录结构排好的 `.md`
- 需要从 Excel / PPT 里把表格和幻灯片文字抠出来的人
- 内网、无外网、没装 Python 的机器（用离线包）

## 用户交什么材料

一句话：**一个文件路径、一个网址、一段管道输入，或者一个文件夹**。

| 输入 | 例子 |
| --- | --- |
| 单个文件 | `报告.pdf`、`合同.docx`、`数据.xlsx`、`汇报.pptx` |
| 网址 | `https://example.com/a.pdf` |
| 管道输入 | `cat a.pdf \| ... - -x pdf` |
| 整个文件夹 | `./资料`，加 `--recursive` 连子目录一起 |

支持的格式：pdf、docx、xlsx、xls、csv、pptx、html、txt、json、xml、ipynb、epub、zip、jpg/png（仅元数据）、mp3/wav（需音频转写后端）。

## 拿到什么结果

- 纯 Markdown：标题层级、表格（Markdown 表格）、脚注（`[[1]](#footnote-1)` + 末尾列表）、幻灯片按 `<!-- Slide number: N -->` 分节
- 批量模式每个源文件一个 `.md`，输出目录镜像输入目录结构；同名不同文件夹不会互相覆盖
- 转换失败的单个文件单独报错、不影响其余文件，退出码 1；跳过的文件会给出原因（不支持的扩展名、本身就是 Markdown）
- 加 `--json` 得到机器可读汇总，便于接自动化

## 限制（发布时请原样保留这一段）

- **不 OCR**：扫描件 PDF、图片里的文字转出来是空的。先用 `tesseract` 之类做 OCR 再转
- `.doc` / `.ppt` 老格式不支持，先另存成 `.docx` / `.pptx`
- 图片只读 `.jpg` / `.jpeg` / `.png` 的元数据，图内文字丢失
- 音频默认只出元数据，转文字要额外的转写后端
- 电子表格出来是 Markdown 表格，不是 CSV
- 首次运行需要联网下载转换引擎（约 1-2 分钟），之后走缓存；完全离线的机器用离线包

## 结果图分镜（录一次真实操作即可）

1. 桌面上一个 `资料/` 文件夹，里面 4-5 个不同类型的文件（PDF + Word + Excel + PPT）
2. 执行 `python3 scripts/convert.py 资料 --recursive --output-dir md`
3. 镜头给终端最后几行：每个文件的字符数、`✅` 汇总、耗时
4. 打开 `md/` 目录，点开其中一个 `.md`，显示表格和标题层级
5. 结尾一句：适合谁（把资料喂给 AI 的人）

画面里出现的文件请用自造的样例，不要放客户真实资料。

## 定价建议

- **一次性付费**更合适：转文档是"交一次材料拿一次结果"的活，没有持续维护承诺
- 若按月订阅，介绍里必须写清每月维护什么（上游版本跟进、格式新增），否则按退款风险定价
- 定前先算：首次下载与转换的等待时间、售后答疑、平台服务费（内测页面显示 1%）
- **内测期已发布的免费资产不支持转付费**，收费与否要在首次提交前定下来（官方 FAQ）
